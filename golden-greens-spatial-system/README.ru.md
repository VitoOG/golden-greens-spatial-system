# Golden Greens Spatial Product System

**MVP 0.1 — локальный параметрический 3D-каталог CEA-продуктов и производственной инфраструктуры.**

Проект предназначен для первичной сборки линейки Golden Greens: от клонарника и growbox до многокамерных корпусов, контейнерных комплексов, теплиц и интегрированного производственного кампуса.

Это стартовый инженерно-визуальный пакет, а не завершённая CAD/CAE-система и не рабочая проектная документация.

## Что уже реализовано

- Браузерный сайт без внешних CDN и серверной части.
- Интерактивная WebGL-сцена: вращение, панорамирование, масштабирование, выбор объектов.
- 11 исходных продуктовых семейств: nursery, vegetarium, growbox, growroom, 3/9/10 камер, контейнер 40 HC, хаб из 10 контейнеров, теплица, turnkey campus.
- Генерация условной 3D-геометрии: каркас, стеллажи, грядки, LED-модули, баки, смесительный и насосный узлы, орошение, климатический блок, PLC-шкаф, edge/server, лаборатория, seed bank, склад.
- Редактирование габаритов, количества камер/модулей, стеллажей/грядок, ярусов и расчётных входов.
- Предварительные расчёты площади пола, валового объёма, площади выращивания, LED-мощности, суточной энергии LED и расхода воздуха по ACH.
- Экспорт паспорта конфигурации в JSON, BOM в CSV, сцены в OBJ + MTL.
- Исходники компонентной библиотеки OpenSCAD.
- Макрос FreeCAD для построения параметрической стартовой модели.
- Скрипт создания отдельных OBJ-компонентов для импорта в Blender.

## Запуск

Требуется современный браузер с WebGL 1.0 и Python 3 (для локального статического сервера). Node.js не требуется.

### Linux / macOS

```bash
cd golden-greens-spatial-system
./run-local.sh
```

Откройте `http://127.0.0.1:8000`.

### Windows

Запустите `run-local.bat`, затем откройте `http://127.0.0.1:8000`.

Можно запустить и вручную:

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

Не открывайте `index.html` напрямую через `file://`: ES-модули могут блокироваться политикой браузера.

## Управление 3D-сценой

- ЛКМ + перетаскивание — вращение камеры.
- Колесо мыши — приближение/отдаление.
- Shift + перетаскивание или правая кнопка — панорамирование.
- Клик по объекту — выбор и паспорт.
- Слои сцены — включение/выключение групп объектов.
- Поля справа — изменение параметров модели.

На мобильных устройствах поддерживается сенсорное вращение/масштабирование в пределах возможностей браузера; полноценная проверка мобильного UX ещё не выполнена.

## Расчётная модель MVP

### Геометрия

- Площадь пола: `A_floor = L × W`.
- Валовый объём: `V_gross = L × W × H`.
- Площадь выращивания для стеллажей: сумма `rack_length × rack_width × number_of_levels`.
- Площадь выращивания грядок: сумма посадочных поверхностей грядок.

### LED

`P_LED [W] ≈ A_grow [m²] × PPFD [µmol/(m²·s)] / PPE [µmol/J]`.

`E_LED [kWh/day] = P_LED [W] × photoperiod [h/day] / 1000`.

Это предварительная идеализированная оценка. Она не учитывает равномерность PPFD, оптику, высоту подвеса, потери драйвера, коэффициенты использования потока и тепловое взаимодействие.

### Воздухообмен

`Q [m³/h] = V_gross [m³] × ACH [1/h]`.

ACH должен быть обоснован технологией, влаговыделением, тепловой нагрузкой, загрязнениями и режимом работы. Это не подбор вентилятора или HVAC.

OpenSCAD sanity render (example):

```bash
openscad -o /tmp/gg-growroom.stl -D 'MODEL="growroom"' openscad/gg_product_template.scad
```

The starter assemblies use intersecting conceptual solids and may emit a non-manifold warning on STL export. Use OBJ assets for visual composition; split/repair solids and validate manufacturing geometry before any fabrication export.

## Ограничения и честная граница применимости

В этой версии намеренно **не выполняются**:

- расчёт отопления/охлаждения, осушения и полной психрометрии;
- водный баланс по культуре, транспирации и режимам полива;
- гидравлический расчёт труб, фильтров, насосов, напора и NPSH;
- расчёт электрических линий, токов КЗ, селективности, PE, кабелей, фазного баланса и резервов;
- расчёт несущей способности, фундаментов, снеговых/ветровых нагрузок и узлов соединений;
- пожарные, эвакуационные, санитарные и строительные проверки;
- vendor-validated подбор моделей оборудования;
- реальная телеметрия, PLC/SCADA runtime и физическое управление.

Мощности насосов/вентиляторов/контроллеров в профилях — демонстрационные ориентиры для формирования структуры BOM, а не утверждённые спецификации. HVAC и осушение показываются геометрически, но не рассчитываются.

Перед закупкой, строительством или эксплуатацией каждую систему требуется отдельно спроектировать, проверить по паспортам поставщиков и применимым нормам, а затем независимо верифицировать.
